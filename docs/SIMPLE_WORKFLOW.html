📝 รายละเอียดการทำงาน 4 ขั้นตอน

1. แตะบัตรหน้าห้องเรียน (IoT Data Ingestion)

นักศึกษาหรืออาจารย์แตะบัตรที่หน้าห้องเรียน (เช่น B316, B317) ข้อมูลเวลาสแกนจะไหลจากเครื่องแตะบัตรกลุ่ม 6 เข้ามาบันทึกในตาราง web_app อัตโนมัติทุก 5 วินาที

2. ล็อกอินเข้าสู่ระบบ (Authentication via Group 3)

ผู้ใช้เปิดหน้าเว็บแล้วกรอกรหัส ระบบจะส่งไปตรวจกับ API กลุ่ม 3 เพื่อยืนยันตัวตนและตรวจสอบสิทธิ์ว่าเป็น "นักศึกษา" (Student) หรือ "อาจารย์" (Teacher)

3. แยกหน้าจอตามบทบาท (Role-based View & Security)

  • นักศึกษา (Student): ล็อกสิทธิ์ให้ดูได้เฉพาะประวัติของตนเองเท่านั้น ซ่อนช่องค้นหาคนอื่น (IDOR Protection)
  • อาจารย์ (Teacher): ดูประวัติของทุกคนทุกห้องเรียนได้ มีช่องค้นหารหัสนักศึกษา และดูสถิติภาพรวมทั้งมหาวิทยาลัย

4. ตรวจเช็กคนในห้องเรียนแบบ Real-time (Active Occupancy Tracking)

เมื่อเลือกสถานะ "กำลังใช้งาน" (ACTIVE) ระบบจะแสดงเฉพาะคนที่แตะบัตรเข้าห้อง (IN) และยังไม่ได้แตะบัตรออก (OUT) ทำให้รู้ได้ทันทีว่าใครอยู่ในห้องขณะนี้
