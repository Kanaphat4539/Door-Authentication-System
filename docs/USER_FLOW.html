👨‍🏫

หากเป็น อาจารย์ (Teacher)

สิทธิ์การเข้าถึงข้อมูลและเครื่องมือค้นหาระดับภาพรวม

📊 1. การ์ดสรุปสถิติภาพรวม

  • • แสดงห้องที่มีการใช้ทั้งหมดกี่ห้อง
  • • สถิติการเข้าใช้ห้องเรียนรายวัน
  • • แสดงข้อมูลภาพรวมทั้งหมด ไม่ลดตามการค้นหา

📋 2. การดูประวัติการเข้าใช้ห้อง

  • • สามารถดูประวัติการเข้าใช้ห้องทั้งหมด

🔍 3. การค้นหาประวัติการเข้าใช้ห้อง

สามารถค้นหาประวัติการเข้าใช้ห้องได้จาก:

  • 1. รหัสนักศึกษา
  • 2. ห้อง
  • 3. วัน
  • 4. เวลา
  • 5. สถานะ (ทั้งหมด, เข้าห้อง IN, ออกห้อง OUT, กำลังใช้งาน ACTIVE)
🧑‍🎓

หากเป็น นักศึกษา (Student)

สิทธิ์การเข้าถึงข้อมูลและเครื่องมือค้นหาระดับส่วนบุคคล

📊 1. การ์ดสรุปสถิติส่วนบุคคล

  • • แสดงเฉพาะข้อมูลสถิติทั้งหมดของตนเอง (จำนวนครั้งที่เข้าเรียน, จำนวนห้องที่เคยเข้า)
  • • แสดงข้อมูลทั้งหมดของตนเอง ไม่ลดตามการค้นหา

📋 2. การดูประวัติและการค้นหาประวัติการเข้าใช้ห้อง

สามารถดูและค้นหาประวัติการเข้าใช้ห้องได้จาก:

  • 1. ห้อง
  • 2. วัน
  • 3. เวลา
  • 4. สถานะ (ทั้งหมด, เข้าห้อง IN, ออกห้อง OUT, กำลังใช้งาน ACTIVE)
  • * ดูได้เฉพาะข้อมูลประวัติตนเองเท่านั้น ไม่มีช่องให้ค้นหารหัสนักศึกษาคนอื่น (Anti-IDOR)

⚖️ ตารางสรุปเปรียบเทียบการใช้งานระหว่าง อาจารย์ vs นักศึกษา

หัวข้อ บทบาท อาจารย์ (Teacher) บทบาท นักศึกษา (Student)
การ์ดสรุปสถิติ แสดงห้องที่มีการใช้ทั้งหมดกี่ห้อง, สถิติการเข้าใช้ห้องเรียนรายวัน (แสดงข้อมูลภาพรวมทั้งหมด ไม่ลดตามการค้นหา) แสดงเฉพาะข้อมูลสถิติทั้งหมดของตนเอง (ไม่ลดตามการค้นหา)
การดูประวัติการเข้าใช้ห้อง สามารถดูประวัติการเข้าใช้ห้องทั้งหมด สามารถดูประวัติการเข้าใช้ห้องเฉพาะของตนเอง
เงื่อนไขที่สามารถค้นหาได้ ค้นหาได้จาก: รหัสนักศึกษา, ห้อง, วัน, เวลา, สถานะ ค้นหาได้จาก: ห้อง, วัน, เวลา, สถานะ (ไม่มีรหัสนักศึกษา)
