🔑 ส่วนที่ 1: การยืนยันตัวตน และค้นหาประวัติ

  • ผู้ใช้งาน (Actors): นักศึกษา (ดูเฉพาะประวัติตนเอง - Anti-IDOR) และ อาจารย์ (ค้นหาได้ทุกคนและทุกห้อง)
  • Frontend (Next.js): หน้า Login (เก็บ JWT ใน localStorage) และหน้า Dashboard (ตัวกรอง, ค้นหา, สลับภาษา TH/EN)
  • FastAPI Backend: ตรวจสอบสิทธิ์กับกลุ่ม 3, ออก JWT Token (HS256, 120m), บันทึก Audit Log ลงตาราง user
  • Central Auth (กลุ่ม 3): ตรวจรหัสผ่าน และส่งคืน Role กับข้อมูลจริง

📡 ส่วนที่ 2: ระบบนำเข้าและประมวลผลข้อมูล IoT

  • เครื่องแตะบัตร (Hardware): เครื่องอ่านบัตร RFID/NFC ประจำห้องเรียน บันทึกสถานะเข้า (IN) และออก (OUT)
  • IoT Server (กลุ่ม 6): เซิร์ฟเวอร์รวบรวม Log การแตะบัตร (192.168.100.106:3000)
  • IoT Sync Worker: Background Daemon ดึงข้อมูลทุก 5 วิ, ทำ Data Cleansing, แปลงเวลา GMT+7, ตัดข้อมูลซ้ำ (Deduplicate)
  • MariaDB (ตาราง web_app): อัปเดตประวัติแตะบัตรแบบ Real-time พร้อมคำนวณสถานะกำลังใช้งาน (ACTIVE)
