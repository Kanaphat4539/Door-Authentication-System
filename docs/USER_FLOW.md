## 📌 สรุปเส้นทางการใช้งานของผู้ใช้ (User Flow Summary)

ผู้ใช้ทุกคนเริ่มต้นเข้าใช้งานจาก **หน้าเข้าสู่ระบบ (Login Page)** ร่วมกัน โดยส่งตรวจสอบรหัสผ่านกับระบบกลุ่ม 3 และรับ Token ของกลุ่ม 4 จากนั้นระบบจะแยกเส้นทางตามบทบาท (Role) ดังนี้:

### 👨‍🏫 หากเป็น อาจารย์ (Teacher):
1. **การ์ดสรุปสถิติภาพรวม:** แสดงข้อมูลสถิติภาพรวมทั้งหมด ได้แก่ จำนวนห้องที่มีการใช้งานทั้งหมด, สถิติการเข้าใช้ห้องเรียนรายวัน (การ์ดจะคงค่าสถิติรวมของระบบเสมอ ไม่ลดลงตามการค้นหา)
2. **สามารถดูประวัติการเข้าใช้ห้องทั้งหมด**
3. **ค้นหาประวัติการเข้าใช้ห้องได้จาก:**
   * **รหัสนักศึกษา**
   * **ห้อง**
   * **วัน**
   * **เวลา**
   * **สถานะ** (ทั้งหมด, เข้าห้อง `IN`, ออกจากห้อง `OUT`, หรือกำลังใช้งาน `ACTIVE`)

---

### 🧑‍🎓 หากเป็น นักศึกษา (Student):
1. **การ์ดสรุปสถิติส่วนบุคคล:** แสดงเฉพาะข้อมูลสถิติทั้งหมดของตนเอง (จำนวนครั้งที่เข้าเรียน, จำนวนห้องที่เคยเข้า) ไม่แสดงตามการค้นหา
2. **สามารถดูประวัติการเข้าใช้ห้องได้จาก:**
   * **ห้อง**
   * **วัน**
   * **เวลา**
   * **สถานะ** (ทั้งหมด, เข้าห้อง `IN`, ออกจากห้อง `OUT`, หรือกำลังใช้งาน `ACTIVE`)  
   *(หมายเหตุ: ป้องกัน IDOR โดยล็อกให้ดูได้เฉพาะข้อมูลของตนเอง และไม่มีช่องให้ค้นหารหัสนักศึกษาคนอื่น)*

## 🖼️ แผนภาพ User Flow Diagram (Mermaid)

```mermaid
flowchart TD
    %% Start
    Start(["🌐 ผู้ใช้เข้าสู่เว็บแอปพลิเคชัน\n(http://172.16.10.200:3001)"]) --> CheckAuth{"🔐 มี Token ในระบบ\nที่ยังไม่หมดอายุ?"}

    %% Login Path
    CheckAuth -- ไม่มี / หมดอายุ --> LoginPage["📄 หน้าเข้าสู่ระบบ (Login Page)\n- กรอก Username & Password\n- เลือกระบบภาษา (TH / EN)"]
    LoginPage --> SubmitLogin["🚀 กดเข้าสู่ระบบ (POST /api/v1/auth/login)"]
    SubmitLogin --> VerifyG3["🔍 ส่งกลุ่ม 3 ตรวจสอบรหัสผ่าน"]
    VerifyG3 -- ไม่ถูกต้อง --> LoginError["❌ แจ้งเตือน 'ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง'"]
    LoginError --> LoginPage
    VerifyG3 -- ถูกต้อง --> IssueJWT["🎟️ Backend กลุ่ม 4 ออก JWT Token (อายุ 120 นาที)"]
    IssueJWT --> SaveToken["💾 บันทึกลง localStorage และ Redirect เข้า Dashboard"]

    %% Authenticated
    CheckAuth -- มี Token ถูกต้อง --> DirectDash["🚀 เข้าสู่หน้า Dashboard"]
    SaveToken --> DirectDash

    DirectDash --> RoleSplit{"👤 ตรวจสอบสิทธิ์ (Role)"}

    %% TEACHER FLOW
    RoleSplit -- role == 'teacher' --> TeacherDash["👨‍🏫 หน้าจออาจารย์ (Teacher Dashboard)"]
    
    subgraph TeacherJourney ["🎯 เส้นทางการใช้งานของอาจารย์ (Teacher)"]
        TeacherDash --> T1["📊 การ์ดสถิติภาพรวม:\n- แสดงสถิติห้องที่มีการใช้ทั้งหมด\n- สถิติการเข้าใช้ห้องเรียนรายวัน\n(คงค่าสถิติรวมทั้งหมด ไม่ลดตามการค้นหา)"]
        T1 --> T2["📋 สามารถดูประวัติการเข้าใช้ห้องทั้งหมด"]
        T2 --> T3["🔍 ค้นหาประวัติการเข้าใช้ห้องได้จาก:\n• รหัสนักศึกษา\n• ห้อง\n• วัน\n• เวลา\n• สถานะ (IN / OUT / ACTIVE)"]
    end

    %% STUDENT FLOW
    RoleSplit -- role == 'student' --> StudentDash["🧑‍🎓 หน้าจอนักศึกษา (Student Dashboard)"]

    subgraph StudentJourney ["🎯 เส้นทางการใช้งานของนักศึกษา (Student)"]
        StudentDash --> S1["📊 การ์ดสถิติส่วนบุคคล:\n- แสดงเฉพาะข้อมูลสถิติทั้งหมดของตนเอง\n(ยอดเข้าเรียน, ห้องที่เคยเข้า ไม่ลดตามการค้นหา)"]
        S1 --> S2["📋 สามารถดูประวัติการเข้าใช้ห้องได้จาก:\n• ห้อง\n• วัน\n• เวลา\n• สถานะ (IN / OUT / ACTIVE)\n*(เฉพาะข้อมูลของตนเองเท่านั้น)*"]
    end

    %% Common Actions
    T3 --> CommonNav["⚙️ ฟังก์ชันร่วม (Header Navigation)"]
    S2 --> CommonNav

    CommonNav --> LangToggle["🌐 สลับภาษา (ไทย 🇹🇭 / English 🇺🇸)"]
    CommonNav --> LogoutAction["🚪 ออกจากระบบ (Logout)"]
    LogoutAction --> ClearSession["🗑️ ลบ Token ออกจากเบราว์เซอร์"]
    ClearSession --> LoginPage
```

## ⚖️ ตารางสรุปเปรียบเทียบการใช้งานระหว่าง อาจารย์ vs นักศึกษา

| ส่วนประกอบ | บทบาท อาจารย์ (Teacher) | บทบาท นักศึกษา (Student) |
|---|---|---|
| **การ์ดสรุปสถิติ** | • แสดงห้องที่มีการใช้ทั้งหมดกี่ห้อง<br>• สถิติการเข้าใช้ห้องเรียนรายวัน<br>*(แสดงข้อมูลภาพรวมทั้งหมด ไม่ลดตามการค้นหา)* | • แสดงเฉพาะข้อมูลสถิติทั้งหมดของตนเอง<br>*(ไม่แสดงข้อมูลคนอื่น และไม่ลดตามการค้นหา)* |
| **การดูประวัติเข้าใช้ห้อง** | **สามารถดูประวัติการเข้าใช้ห้องทั้งหมด** | **สามารถดูประวัติการเข้าใช้ห้องเฉพาะของตนเอง** |
| **เงื่อนไขที่สามารถค้นหาได้** | ค้นหาได้จาก:<br>1. **รหัสนักศึกษา**<br>2. **ห้อง**<br>3. **วัน**<br>4. **เวลา**<br>5. **สถานะ** | ค้นหาได้จาก:<br>1. **ห้อง**<br>2. **วัน**<br>3. **เวลา**<br>4. **สถานะ**<br>*(ไม่มีรหัสนักศึกษา ป้องกัน IDOR)* |
| **การซิงก์ข้อมูล IoT** | มีปุ่มกดสั่งซิงก์ดึงข้อมูลสดจากกลุ่ม 6 | ซิงก์ข้อมูลอัตโนมัติผ่าน Background Worker |
| **การออกจากระบบ** | กด Logout ลบ Token กลับสู่หน้า Login | กด Logout ลบ Token กลับสู่หน้า Login |
