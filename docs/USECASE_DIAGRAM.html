📋 ตารางเปรียบเทียบสิทธิ์และ Use Cases (Student vs Teacher)

Use Case (ฟังก์ชันการใช้งาน) นักศึกษา (Student) อาจารย์ (Teacher) คำอธิบายและความปลอดภัย
1. เข้าสู่ระบบ (Login) ✅ ✅ ส่งไปตรวจสอบ Username/Password กับ API กลุ่ม 3
2. ออกจากระบบ (Logout) ✅ ✅ ลบ Token ออกจาก Browser Session
3. สลับภาษา (TH / EN) ✅ ✅ สลับภาษาในหน้า Dashboard และตารางข้อมูล
4. ขอบเขตข้อมูลประวัติแตะบัตร เฉพาะของตนเอง ทุกคนทุกห้อง IDOR Protection: ล็อก Scope ให้นักศึกษาดูได้เฉพาะของตนเอง
5. ค้นหารหัสนักศึกษาคนอื่น ❌ (ซ่อนช่องค้นหา) ✅ อาจารย์สามารถพิมพ์ค้นหารหัสนักศึกษาคนใดก็ได้
6. กรองตามห้องเรียน / วันที่ / เวลา ✅ (ของตนเอง) ✅ (ของทุกคน) กรองตามห้องเรียน วันที่ และช่วงเวลา
7. ค้นหาสถานะ "กำลังใช้งาน" (ACTIVE) ✅ ✅ แสดงเฉพาะคนที่กำลังใช้งานห้องเรียนล่าสุด (มีแค่ IN ยังไม่ OUT)
8. การ์ดสถานะห้องเรียน (activeRooms) ห้องที่ตนเองเข้าวันนี้ ทุกห้องที่เปิดใช้งานวันนี้ คำนวณจำนวนห้องที่ active ตามบทบาท
9. การ์ดยอดการเข้าใช้งาน (totalAccess) ยอดสแกนบัตรของฉัน ยอดสแกนบัตรของทุกคน สรุปจำนวนครั้งการแตะบัตรเข้า-ออกห้องเรียน
