# Auth API Implementation Plan

> **For agentic workers:** Execute inline using the available host tools. The referenced superpowers execution sub-skills are not installed.

**Goal:** Create a runnable authentication API while leaving RADIUS server values blank.

**Architecture:** Separate environment settings, JSON schemas, RADIUS authentication,
JWT issuance/validation, and routes. Explicit development mock mode supports testing
before the external service is available.

**Tech Stack:** Python 3.14, FastAPI, Pydantic Settings, PyJWT, pyrad, pytest, httpx2.

**Spec:** `docs/superpowers/specs/2026-10-07-auth-api-design.md`

## Global Constraints

- Never commit real secrets or restore existing deleted files.
- JSON login; Bearer token for `/auth/me`; no invented roles or door permissions.
- Unconfigured RADIUS returns 503; mock mode is explicit, never an automatic fallback.
- RADIUS PAP only; confirm compatibility with the external team.
