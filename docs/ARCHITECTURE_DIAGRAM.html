❌ ข้อผิดพลาดเดิมในรูปเก่า

  • เส้น Frontend ➔ MariaDB: ผิดหลัก Security และ 3-Tier Architecture อย่างยิ่ง เพราะหน้าบ้านไม่สามารถและต้องไม่ต่อกับ Database โดยตรง
  • เส้น Nginx ➔ IOT Sync: Nginx เป็นเพียง Web Server/Proxy ไม่ได้มีเส้นทางส่ง Request ไปยัง Worker ของ IoT โดยตรง
  • คำสะกดผิด: สะกดว่า Fronted (ตกตัว n)

✅ สิ่งที่ปรับปรุงในฉบับแก้ไขนี้

  • ตัดเส้น Frontend ➔ Database ออก: ปลอดภัยตามมาตรฐานความปลอดภัย
  • เพิ่มเส้นเชื่อม Frontend ➔ Backend API: Frontend เรียกใช้งานผ่าน REST API พร้อมแนบ Bearer Token
  • ตัดเส้น Nginx ➔ IOT Sync ออก: วาง IOT Sync เป็น Background Worker ที่ดึงข้อมูลจากกลุ่ม 6 บันทึกลง MariaDB
  • แก้ไขคำสะกดเป็น: Frontend ถูกต้อง 100%
